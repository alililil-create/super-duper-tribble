# 语义评分与人工校准

`app/judge.py:RUBRICS` 给出了客服、问数、场景各两个语义维度的 1/3/5 分锚点；Judge 使用 Qwen-max，结构化校验 1-5 整数和理由，拒绝遗漏或重复维度。

当前提交没有真人标注，校准状态为**待完成**。下面仅为数据格式说明，不是测评事实，不应复制示例分数当作真人标注。

人工标注 JSON 为列表，每项字段：

- `id`：原用例 ID。
- `source`：真人完成时填写 `human`。
- `annotator`：实际标注人标识。
- `output_id`：`运行ID:用例ID:v2`，必须与 Judge 文件一致。
- `scores`：维度名到 1-5 整数的映射，必须覆盖该能力所有维度。

至少三条真实人工标注后运行：

```powershell
uv run python -m app.judge artifacts/latest.json --human 自己的标注.json
```

脚本对同一快照重新生成 Judge 分数并计算 MAE。公式：所有人工分与机器分的绝对差之和 / 匹配分数总数，同时按能力和维度报告。阈值为严格 `<1.0`；机器服务错误、维度缺失、快照不一致或标注来源不符时不会输出通过结论。
