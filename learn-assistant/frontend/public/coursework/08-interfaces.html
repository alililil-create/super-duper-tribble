以下接口从正在运行的 /openapi.json 读取，与 Swagger 一致。

方法路径操作认证
POST/api/articlesCreate ArticleBearer JWT
GET/api/articlesArticlesBearer JWT
GET/api/articles/{article_id}Article DetailBearer JWT
POST/api/scenes/generateGenerateBearer JWT
GET/api/scenesScenesBearer JWT
GET/api/scenes/{scene_id}Scene DetailBearer JWT

文章：title、content、level、source

场景：article_id、title、user_role、goal、ai_roles、conflict、task_chain、language_goals、final_output、difficulty

422：参数校验失败；401：未登录；404：文章或场景不存在。
