07 修改的文件及原因

Learn Assistant · 本机项目 · 2026-10-20

后端分层：配置 / 数据访问 → ORM 模型 → 数据校验 → API 路由 → 千问服务

文件实现原因
app/config.py统一读取环境配置数据库、JWT、千问配置不硬编码
app/db.py异步引擎与每请求会话连接池复用，结束自动释放
app/models.py用户/文章/场景/会话/消息模型字段、外键和 JSON 数据持久化
app/schemas.py请求与返回结构校验限制长度和难度，过滤密码字段
app/auth.py密码哈希与 JWT 认证识别用户，保护业务接口
app/main.py文章/场景/会话路由组合认证、查询、事务与错误响应
app/llm.py千问生成与回复服务JSON 校验重试，避免重复消息
frontend/src/Workspace.vue文章、场景和对话页面连接 API，展示真实数据
