# 实现文件及原因

这是独立的新课程项目，未改写之前的 LangGraph 作业。

| 文件 | 作用与原因 |
|---|---|
| backend-fastapi/app/config.py | 用环境变量读取数据库、JWT、千问配置，固定 .env 查找位置 |
| app/db.py | 异步引擎、连接池、每请求会话，避免共享 AsyncSession |
| app/models.py | 定义用户、文章、场景、会话、消息五表；JSON 存储角色与任务链 |
| app/schemas.py | 请求校验、响应过滤、场景结构验证与长度限制 |
| app/auth.py | bcrypt 哈希、JWT 签发/验签和登录依赖 |
| app/main.py | 按模块标签组织 API，资源查询、事务及用户隔离 |
| app/llm.py | 封装异步千问调用，场景 JSON 重试与角色对话 |
| frontend/src/Workspace.vue | 登录注册、文章库、场景卡与聊天完整页面 |
| frontend/src/api.ts | 统一认证请求与错误处理，Pinia 会话状态 |
| frontend/vite.config.ts | Vue 插件及 /api 代理，开发端口 5173 |
| tests/test_workflow.py | 认证、校验、共享资源、私有会话与失败容错测试 |
| scripts/demo_online.py | 真实 MySQL/Qwen 联调，生成可截图的终端记录 |

相对讲义的修正：

1. 阶段 2 第 11、24 页明确文章/场景共享，而后面的验收描述出现“各自可见”的冲突。本实现遵循前述正文；阶段 3 的学习会话与消息严格隔离。
2. 注册直接依赖数据库唯一约束并捕获冲突，避免并发查重失效和用户名/邮箱分别命中两行引起 scalar_one_or_none 异常。
3. bcrypt 按 UTF-8 字节限制到 72，避免讲义 128 字符上限与算法限制冲突。
4. 场景服务实际加入一次校验重试，限定难度枚举及非空角色/任务；不把上游响应原文返回客户端。
5. 用户消息先落库后再读取历史，不再次 append 同一条消息；历史按 ID 确定顺序。
6. 页面可按分页加载历史记录；会话更新显式设置 updated_at。创建会话加 user_id+scene_id 唯一约束以防重复。
7. 修正 MySQL 8 caching_sha2_password 认证的 cryptography 依赖；锁文件记录可复现版本。
8. 当前是课堂单进程服务，部署扩展事项如实记录，不宣称已经完成生产部署。

技术核对来源：[SQLAlchemy 异步会话](https://docs.sqlalchemy.org/en/20/orm/extensions/asyncio.html)、[FastAPI JWT](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/)、[千问结构化输出](https://help.aliyun.com/en/model-studio/qwen-structured-output)。
