测试边界：自动化逻辑测试使用隔离 SQLite 和明确的模型替身；在线脚本与浏览器使用真实 MySQL/Qwen。尚未进行公网部署、负载测试或多进程并发验证。

启动的开发服务只绑定 127.0.0.1，前端 5173、后端 8000。若端口已有服务，不必重复启动；停掉旧窗口后再运行即可。
