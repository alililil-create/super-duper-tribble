# 文章、场景与学习会话接口设计

所有业务路由使用 `/api` 前缀。注册、登录和健康检查可匿名访问，其他路由需 `Authorization: Bearer <token>`。完整交互式字段定义由 `/docs` 和 `/openapi.json` 提供。

| 方法 | 路径 | 请求 | 成功响应 |
|---|---|---|---|
| GET | /api/health | 无 | 数据库连接检查结果 |
| POST | /api/auth/register | username,email,password | 201，用户信息，无密码 |
| POST | /api/auth/login | username,password | access_token,token_type |
| GET | /api/users/me | JWT | 当前用户 |
| POST | /api/articles | title,content,level,source | 201，完整文章 |
| GET | /api/articles | page≥1,page_size=1..50 | 文章摘要数组，按时间和 ID 降序 |
| GET | /api/articles/{id} | 文章 ID | 完整正文与元数据 |
| POST | /api/scenes/generate | article_id,difficulty | 201，生成并保存的场景 |
| GET | /api/scenes | 可选 article_id,page,page_size | 场景数组 |
| GET | /api/scenes/{id} | 场景 ID | 完整场景卡 |
| POST | /api/sessions | article_id,scene_id | 201，创建或复用当前用户会话 |
| GET | /api/sessions/{id} | 会话 ID | 本人会话与关联场景 |
| POST | /api/sessions/{id}/messages | content | user_message 与 ai_message |
| GET | /api/sessions/{id}/messages | limit=1..100,offset≥0 | 本人消息，按 ID 升序 |

文章标题 1–200 字符，正文 20–15000 字符，level 默认 B1。难度限定 simple/standard/challenge。场景字段为 title,user_role,goal,ai_roles,conflict,task_chain,language_goals,final_output,difficulty。AI 角色含 name,stance,example；任务步骤含 stage,task,user_action。

状态码：401 未登录/无效令牌；404 数据不存在或会话不属于当前用户；409 重复账号/同会话正在回复；422 字段或分页参数不合法；502 模型调用或输出校验失败；503 未配置密钥；504 模型超时。

数据表：users → sessions → messages；articles → scenes；sessions 同时关联 user、article、scene。文章和场景共享，sessions.user_id 是学习内容的访问控制边界。创建会话时校验场景确实属于指定文章，不接受客户端指定 user_id。

运行截图建议：/docs 展开文章与场景路由，终端运行验收脚本；Workbench 查询五张表。
