# 10.20 作业对照与截图说明

| 作业栏目 | 实现 | 截图位置 |
|---|---|---|
| 学习与会话 | 创建/复用会话、历史会话恢复、发送消息、角色回复、私有消息历史 | 右上角“我的学习会话”与对话练习区 |
| 前端代码构建 | Vue 3 + TypeScript + Vite + Pinia + Vue Router + Element Plus；抽出 LearningReport 组件 | PowerShell 执行 pnpm build，显示构建成功 |
| 学习报告 | 真实消息统计、最近表达、Hint 回顾、下一步练习、Markdown 导出；仅本人可读 | 对话区点击“查看学习报告” |
| 流程图（可选） | 登录、文章、场景、会话、对话、报告完整流程 | 打开 docs/学习流程图.svg |

新增接口：GET /api/sessions 查询本人的历史会话（支持分页）；GET /api/sessions/{id}/report 读取本人的学习报告，其他用户访问返回 404。

新增文件：app/report.py 汇总已存储的对话；LearningReport.vue 展示与导出报告。main.py 增加受保护接口，Workspace.vue 增加历史会话和报告入口。报告实时从数据库重算，不另存一份可能过期的结果。

“学习报告”截图未提供详细评分规则，因此本次实现为统计与回顾报告。词数按英文字母单词匹配，不是词汇掌握量；没有进行能力等级、任务完成度或语法正确率评分。Hint 来源于之前实际的千问回复，查看报告不重复调用千问。

## 构建截图命令

```powershell
cd D:\Codex\2026-10-20\learn-assistant\frontend
pnpm build
```

## 页面截图顺序

1. 打开 http://127.0.0.1:5173，使用自己的账号登录。
2. 选择文章和场景，点击“进入场景”，完成至少一轮英文对话。
3. 截取对话区；点击“我的学习会话”可查看并恢复历史记录。
4. 点击“查看学习报告”，截取统计及表达回顾；可导出 Markdown。
5. 在浏览器打开 docs/学习流程图.svg 进行截图。
